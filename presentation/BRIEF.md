## 視覺設計系統

### 色盤
```
背景:      #0D0F14  (near-black)
主 accent: #58CC02  (brand green — Learn8 品牌色)
次 accent: #E8734A  (coral — 用於痛點強調)
訊號色:    #7AC7C4  (teal — 用於 Neuro Link slide)
文字:      #FFFFFF  (主要文字)
文字次要:  rgba(255,255,255,0.6)
```

### 字型（Google Fonts，已在 Learn8 專案中使用）
```
標題 display: 'Righteous', sans-serif
標題 heading: 'Nunito', sans-serif
內文 body:    'Open Sans', sans-serif
```

### Logo / Wordmark
無向量 logo 檔。改用文字 wordmark：
- 字型：Righteous
- "Learn" 白色，"8" 用 #58CC02 並加 text-shadow glow
- 範例 CSS：
  ```css
  .wordmark { font-family: 'Righteous'; }
  .wordmark span { color: #58CC02; text-shadow: 0 0 20px rgba(88,204,2,0.6); }
  ```

### 動畫基礎規則
```
文字淡入:   opacity 0→1 + translateY 8px→0，duration 0.3s，ease-out
卡片進場:   opacity 0→1 + scale 0.97→1，duration 0.4s，ease-out
數字 count-up: 1.2s，easeInOut
slide 過場: fade，0.3s
beat 觸發:  空白鍵 / 右方向鍵
```

## Slide 規格

### Slide 1｜痛點（0:00–0:45）

**版面**：全深色底，中央文字，無媒體。

**Beat 序列**：
1. 進場：黑底空畫面
2. Beat 1：「你有沒有遇過——」大字，Righteous，白色，淡入
3. Beat 2：「盯著一道題目發呆十分鐘，不知道自己在卡什麼。」淡入，Open Sans，較小
4. Beat 3：上方文字淡出，新一行：「線上課程不缺內容，缺的是——此刻該怎麼幫你。」「此刻」高亮 #58CC02
5. Beat 4：底部出現一行紅字 #E8734A，加粗：「系統通常只有在你交卷之後，才能給你回饋。那已經太晚了。」

**台詞**：
> 你有沒有遇過——盯著一道題目發呆十分鐘，不知道自己在卡什麼。不是不想學，是不知道從哪裡開始動。線上課程不缺內容，也不缺學生。缺的是「這個學生，此刻需要什麼」的理解。大部分平台的設計邏輯是：把課程做好，讓學生自己去消化。但學習不是這樣運作的。學生會分心、會挫折、會不知道自己卡在哪裡。而系統通常只有在你交卷之後，才能給你任何回饋。那已經太晚了。

### Slide 6｜Neuro Link（3:35–4:20）

**版面**：
- 整體比其他 slide 更暗（加一層 `rgba(0,0,0,0.3)` overlay）
- 背景：一條緩慢流動的 teal 正弦波形（純 CSS SVG animation，`#7AC7C4`，opacity 0.15）
- 右側 60%：`腦波儀帶入動畫_右邊數據_疲憊通知_demo.mov`，autoplay once
- 左側 40%：文字

**關鍵動畫：左側遮罩收起**
- 影片完整播放（全版），左側有學習者作答區
- Beat 2 觸發時：一個與背景同色的面板從左側滑入（`translateX -100% → 0`，0.5s ease-out），蓋住影片左半部
- 同時右側數據視覺化區域 glow 增強（box-shadow 加亮）
- 視覺效果：「左側收起，聚焦數據」

**Beat 序列**：
1. 進場：文字「即使課程再好，學生還是會有卡住的時刻。」淡入，影片開始播放
2. Beat 1：左側文字更新：「系統偵測到挫折趨勢，介面即時調整。」
3. Beat 2：遮罩動畫執行，左側收起，glow 加強；文字出現：「不是監控學生在做什麼，而是更早理解學生需要什麼。」

**台詞**：
> 即使課程設計得再好、競技再有吸引力，學生還是會有卡住的時刻。Neuro Link 讓系統能在那個當下理解學生，而不是等到之後才知道。學生作答時，系統持續讀取腦波訊號。當偵測到挫折或分心的趨勢，介面會即時調整——可能是一個提示、一個概念拆解、或是一個呼吸的空間。這不是監控學生在做什麼，而是讓系統更早理解學生需要什麼。這個功能目前用合成訊號做驗證，下一階段會接入真實裝置。
