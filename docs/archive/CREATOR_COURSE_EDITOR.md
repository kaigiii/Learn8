# 🎨 Learn8 創作者課程編輯器 (Creator Course Editor) 設計提案

本文件旨在規劃一個功能完整的視覺化課程編輯器，讓一般使用者（創作者）可以自行編排課程結構、加入題型組件、編輯內容文字，並探討功能的介面擺放位置與儲存架構。

---

## 🏗️ 1. 功能擺放位置 (Feature Placement in UI)

我們決定將功能與**現有課程頁面**整合。未來除了能開放將創作者課程上架為公開課程，也可以更方便地與其他使用者分享：
- **位置**：在前端現有的「課程清單 (Courses)」主頁上方、或是「我的自訂課程」分頁中，新增 **「＋ 建立自製課程」** 的按鈕。
- **URL 路徑**：
  - `/courses/custom`：使用者管理的個人自製課程清單主頁。
  - `/courses/[courseId]/edit`：視覺化課程編輯主介面。
- **優點**：架構高度連貫，讓使用者直觀感受到「個人課程」與「系統課程」的統一。未來可以輕鬆一鍵發佈/分享課程。

## 💾 2. 教材儲存與導出架構 (Data Storage & Export Architecture)

我們採用 **「直接存入資料庫、導出時才轉 YAML」** 的模式。

### 儲存機制 (資料庫 CRUD)：
當使用者在介面中編輯課程時，所有變更都直接同步寫入資料庫：
- **`courses` 表**：
  - `user_id`：儲存該創作者的 `UserModel.id`。
  - `status`：預設為 `draft`。
  - `is_published`：可選欄位，用來標記是否公開/分享給他人。
- **優點**：不需建立新表，100% 複用既有的關卡學習（`LessonAttempt`）、競技場系統、節點解鎖邏輯，且反應速度最快。

### 導出與轉換 YAML 審核發佈機制：

為確保教材內容的品質與全站安全性，使用者自製的課程在轉成全站官方公開課程前，需經過管理者審核：

1. **管理者審核介面 (Admin Review)**：
   - 於 `http://localhost:3000/admin` 中新增一個專屬的 **「課程審核」** 標籤/分頁。
   - 管理者可以列表預覽使用者提交的所有待審核自建課程。
   - 點擊課程可以進行完整的 **「題型內容預覽 (Course & Stage Preview)」**，確認無誤後點擊「通過審核並發佈為公開課程」。
2. **自動轉為公開課程 (Export YAML)**：
   - 管理者核可後，後端 API 會拉取該課程的所有 Units、Nodes、Stages 紀錄。
   - 轉換器將這些資料映射為標準的 `public_course.yaml` 格式並自動儲存至 `public_courses/` 目錄中。
   - **應用場景**：官方公開課程不需手動編寫，完全由社群優質課程轉化而來。
3. **分享給他人**：
   - 透過分享連結（如 `/courses/[courseId]/fork`），其他使用者可以直接將該課程複製一份到自己的課程清單中。

## 🖥️ 3. 視覺化課程編輯介面 (Visual Editor UI/UX)

為了提供極佳的使用者體驗，建議編輯介面採用 **「大綱樹狀圖 + 題型元件市集 + 屬性設定面板」** 的三欄式佈局：

```
+-----------------------------------------------------------------------------------+
|  [回創作者中心]        課程名稱：Python 進階開發實戰             [儲存] [發佈]      |
+-----------------------------------------------------------------------------------+
|  (左欄) 課程大綱樹狀圖   |  (中欄) 關卡題型內容編輯器            | (右欄) 題型預覽與參數  |
|                         |                                      |                     |
|  + Unit 1: 基礎複習     |  目前節點: 第一關：環境建置           | * 題型：MultipleChoice|
|    - 第一關：環境建置   |                                      | * 難度：[Medium   ▼]|
|    - 第二關：變數進階   |  [新增題型組件 ▼]                     |                     |
|                         |  +--------------------------------+  |  [即時預覽組件視覺] |
|  + Unit 2: 函數式編程   |  | 組件 1: MultipleChoice         |  |                     |
|                         |  | 題目文字: [___________________] |  |  +----------------+ |
|  [+] 新增 Unit          |  | 選項 A:   [___________________] |  |  |   預覽畫面...  | |
|  [+] 新增 Node          |  | 選項 B:   [___________________] |  |  +----------------+ |
|                         |  +--------------------------------+  |                     |
+-------------------------+--------------------------------------+---------------------+
```

### 1. 左欄：課程大綱樹狀圖 (Unit/Node Tree)
- 讓創作者能建立、重新命名、刪除 **Units**。
- 每個 Unit 底下可以加入多個 **Nodes**（課程中的每個小地圖節點/關卡）。

### 2. 中欄：關卡題型內容編輯器 (Node & Component Editor)
- 當創作者在左欄選中某個 **Node** 時，中欄會顯示該 Node 內含的所有 **題型組件 (Lesson Stages)**。
- 點擊「新增題型組件」按鈕，展開下拉選單或彈出市集，可以選擇目前的各種組件：
  - `MultipleChoice` (單選題)
  - `Ordering` (排序題)
  - `MatchingPairs` (連連看)
  - `FeynmanMirror` (費曼鏡像)
  - `ExplainerMedia` (媒體解說)
  - `ShortAnswer` (簡答題)
- 根據所選的題型組件，**動態渲染對應的填空輸入欄位**：
  - 舉例：若選 `MultipleChoice`，中欄動態長出 `question`、`options`、`correctAnswer` 欄位供使用者編輯。
  - 這些填空資料最後會組成 `LessonStageModel.content_json`。

### 3. 右欄：題型預覽與詳細參數 (Inspector & Preview)
- 調整此組件的 **難度 (difficulty)**、**標籤 (topic)**、**回饋文字 (success/error feedback)**。
- **實時預覽 (Live Preview)**：當創作者修改中欄文字時，右欄可以即時使用前端現有的渲染器（如 `MultipleChoiceStageRenderer`），渲染出實際學生看到的答題介面，達到「所見即所得」的流暢體驗。

## 🛠️ 4. 開發計畫與步驟

為了安全且高效地開發此功能，我們建議分階段進行：

### 第一階段：資料庫與後端 API 擴展
1. **建立創作者課程 API 端點**：
   - `POST /api/v1/studio/courses`：建立新課程草稿。
   - `GET /api/v1/studio/courses`：獲取自己建立的所有課程清單。
   - `GET /api/v1/studio/courses/{id}`：獲取特定課程的大綱與詳細題型組件內容。
   - `PUT /api/v1/studio/courses/{id}`：儲存更新的課程大綱、節點、題型內容。
   - `POST /api/v1/studio/courses/{id}/publish`：發佈課程。

### 第二階段：前端視覺化編輯器
1. **建立 `/studio` 創作者主頁與儀表板**。
2. **建立視覺化主編輯介面**：實作三欄式佈局，並設計左欄的單元、節點編輯與拖曳機制。
3. **實作組件動態編輯表單**：根據後端提供的 `game_modules` 所定義的 `required_config_data_fields`，動態產生編輯表單。
4. **串接實時預覽功能**。
