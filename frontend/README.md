`npm install`

`npm run dev`

Primary routes:

- `http://localhost:3000/auth/login`
- `http://localhost:3000/auth/welcome`
- `http://localhost:3000/home`
- `http://localhost:3000/store`
- `http://localhost:3000/questionnaire`

Canonical learning routes:

- `http://localhost:3000/courses/:courseId`
- `http://localhost:3000/courses/:courseId/nodes/:nodeId`
- `http://localhost:3000/courses/:courseId/nodes/:nodeId/result`
